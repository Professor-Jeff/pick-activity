# Pick Activity — Train a Neural Network

**Live:** https://professor-jeff.github.io/pick-activity/

A single-file, in-browser demo for COMP 138 where students train a small neural
network to pick an activity. Open the live link, adjust the inputs, and watch
the network learn.

## Deploying

Edit `index.html` and push to `main`. GitHub Pages redeploys within about a minute.
